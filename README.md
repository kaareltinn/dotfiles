### Create symlinks
```
ln -sv ~/dotfiles/nvim/init.lua .config/nvim/init.lua
ln -sv ~/dotfiles/nvim/lua/ .config/nvim/lua/
ln -sv ~/dotfiles/snippets/ .config/nvim/mysnippets
ln -sv ~/dotfiles/.tmux.conf ~/.tmux.conf
ln -sv ~/dotfiles/claude/CLAUDE.md ~/.claude/CLAUDE.md
ln -sv ~/dotfiles/claude/commands ~/.claude/commands
```
